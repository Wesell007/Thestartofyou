# Phase 37C — First Year journey gap register

Audit only. Every moment carries exactly one classification. Gap categories are kept distinct: CONTENT GAP, DISCOVERY GAP, SOURCE / PROVENANCE GAP, ROUTING / LEGACY GAP, EDITORIAL OVERLAP, AI-ONLY NEED. An article that exists but is hard to find is a discovery gap, not uncovered content.

Classification key: C = COVERED, PC = PARTIALLY_COVERED, U = UNCOVERED, NRS = NOT_REQUIRED_STANDALONE, BSE = BETTER_SERVED_ELSEWHERE. Discovery: strong / adequate / weak.
